# DRIVER APP AI AGENT

## 5-Line Summary

Purpose:
Migrate the Driver App authentication from the legacy authentication API to the new Backend V2 Authentication API.

Scope:
Update only the Driver App authentication layer and login flow to match the backend contract.

What Changes:
Authentication endpoints, OTP request/response handling, otp_id flow, session handling, and login integration.

What Will NOT Change:
Driver Home, Duty, Orders, GPS, Notifications, Offer flow, Firebase FCM flow, Driver Context, Subscription logic, UI/UX, Navigation, Backend code, or any unrelated functionality.

Expected Result:
Driver App successfully authenticates using Backend V2 Authentication APIs without any 404 errors while preserving all existing working functionality.

PROBLEM
--------------------------------------------------

The Driver App still uses legacy authentication endpoints.

Current endpoints:

POST /api/auth/send-otp
POST /api/auth/verify-otp
POST /api/auth/verify-pin

Backend has already migrated.

Backend now exposes ONLY:

POST /api/v2/auth/otp/send
POST /api/v2/auth/otp/verify
POST /api/v2/auth/refresh
GET  /api/v2/auth/me
POST /api/v2/auth/logout

Current application receives:

404 Route POST /api/auth/send-otp not found

404 Route POST /api/auth/verify-pin not found

Backend has already been verified.

DO NOT MODIFY BACKEND.
